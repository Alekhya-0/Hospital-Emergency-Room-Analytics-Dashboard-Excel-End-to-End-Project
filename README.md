# Hospital-Emergency-Room-Analytics-Dashboard-Excel-End-to-End-Project

## 🏥 Hospital Emergency Room Dashboard – Project Review

This project is an end-to-end healthcare analytics solution developed in Microsoft Excel to analyze Emergency Room (ER) operations and transform raw patient data into meaningful business insights. The primary objective was to create an interactive dashboard that enables hospital administrators and stakeholders to monitor key performance indicators, evaluate operational efficiency, and make data-driven decisions to improve patient care.

The project began with data preparation using **Power Query Editor**, where the raw dataset was cleaned and transformed by handling missing values, correcting data types, and ensuring data consistency. After preparing the data, relationships were established between multiple tables to create a structured data model that supports accurate analysis and reporting.

Using **Pivot Tables** and **Pivot Charts**, key metrics were analyzed and visualized, including patient volume, average wait time, patient satisfaction score, admission status, attendance status, gender distribution, age-group analysis, and department referrals. Interactive slicers for month and year selection were implemented to allow users to dynamically explore trends and performance across different periods.

The dashboard highlights three critical KPIs:

* **Number of Patients** to track ER utilization.
* **Average Wait Time** to measure operational efficiency.
* **Patient Satisfaction Score** to assess service quality.

Additional analyses provide insights into admission rates, on-time versus delayed attendance, demographic patterns, and referral distributions across departments. These insights help identify bottlenecks, optimize resource allocation, and improve overall patient experience.

Through this project, I demonstrated skills in **data cleaning, data modeling, data analysis, dashboard design, data visualization, and business intelligence reporting** using Excel. The final dashboard serves as a practical tool for monitoring hospital performance and supporting informed decision-making in a healthcare environment.
